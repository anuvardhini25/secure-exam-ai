# SecureExam AI

## Overview
SecureExam AI is an AI-powered online examination platform that ensures secure, fair, and credible remote assessments. It supports MCQs, coding, and short answers while monitoring student behavior in real-time and enforcing anti-cheating measures automatically.

---

## Features
- Real-time AI monitoring: tab switch, copy-paste, right-click, DevTools, and extensions detection  
- Camera motion tracking and live suspicion scoring  
- Loud alarm and AI voice alerts  
- Automatic exam submission for high-risk behavior  
- Admin analytics dashboard with results, violations, and risk levels

---

## Tech Stack
**Frontend:** React.js, Tailwind CSS, Framer Motion, Axios, WebRTC, Web Speech API  
**Backend:** Node.js, Express.js, MongoDB, JWT, bcrypt  
**Tools:** VS Code, Git, Vite
